# Implementation Plan: Dashboard Meal Card Matcher Accuracy

Status: Final
Feature: 011-dashboard-meal-card-matcher-accuracy
Skill: data-science/meals-check

## Summary

This feature fixes the pipeline matching accuracy for meal cards. The dashboard renders matched/missing items generated by `tesco_matcher.py`; currently those items are semantically wrong for some meal types (particularly roast dinners). The 2026-06-13 refinement makes preparation-word matching more flexible while preserving accuracy: raw potatoes can cover roast potatoes, snack/side false positives remain excluded, wrong-format roast proteins such as burgers are excluded, and named roast-dinner components such as broccoli remain required for `covered` status. Fixing this requires changes to `tesco_matcher.py`, not to the dashboard UI.
